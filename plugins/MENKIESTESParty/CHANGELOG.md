# Changelog

## 1.1.0 - 2026-09-09

### Added

- Daily Party Mission shared per Party.
- Daily Mining: 150 target, +40 Party XP.
- Daily Hunter: 30 target, +50 Party XP.
- Daily Farmer: 80 target, +35 Party XP.
- `/party daily` dan `/partydaily`.
- `/partydaily resetall` untuk admin.
- Daily progress reset otomatis berdasarkan tanggal server.

### Changed

- Party War reward otomatis disederhanakan menjadi Party XP saja.
- Default Party War XP: 250.
- Party War tidak lagi memberikan Season Points otomatis.
- Reward senjata/custom item Party War sekarang diberikan manual oleh admin ke perwakilan team.
- Weekly Quest dan Party Relic tetap menggunakan mekanik lama.

### Removed

- Party Hall sebagai sistem reward.
- War Chest reward otomatis.
- Item reward queue/claim dari Party War.
- `/partyhall` command registration.
- `/party hall`, `/party claimchest`, dan `/party rewards` sebagai jalur reward aktif.

## 1.0.4

- Party Level 1 member cap menjadi 5.
- Party War, Weekly Quest, Party Relic, Party GUI dan local YAML storage.
